# TWOM AI 프로토타입 — 코드 구조

이 프로토타입은 Unity 6 / URP로 만들었습니다. 모든 코드는 `Assets/TwomAi/` 아래에 있고, 네임스페이스는 `TwomAi` 하나만 씁니다.
씬은 빌더가 코드로 생성합니다. 각 NPC는 자기 상태 머신(FSM)으로 혼자 판단하고, 경비끼리는 `SquadCoordinator`를 거쳐 정보를 공유합니다. 화면 표시는 HUD 스크립트가 맡습니다.

## 0. 전체 흐름

```
PrototypeSceneBuilder (Editor) ──빌드──▶ 씬 (맵, 웨이포인트, 문, 방, NPC, 플레이어, 시스템)

플레이어 클릭 ─▶ PlayerClickController ─▶ 이동 / 상호작용 / 공격
                     │ 소음
                     ▼
               AiEventBus.EmitNoise ─▶ PerceptionSensor (청각) ─┐
PlayerTarget ─▶ PerceptionSensor (시각) ──────────────────────┤
                                                              ▼
                              GuardBrain / CivilianBrain (FSM)
                                 │ 보고                  │ 이동
                                 ▼                       ▼
                         SquadCoordinator           NpcMover ─▶ WaypointGraph
                                 │ 역할/슬롯 배정
                                 ▼
                           다른 GuardBrain

VisibilitySystem ─▶ RoomVolume (안개) / NpcActor (보임 여부)
TwomHud / AiDebugOverlay ─▶ 화면 표시
```

### 폴더 구성

| 폴더 | 내용 |
|---|---|
| `Scripts/Core` | 공용 타입, 설정, 디렉터, 유틸, 인벤토리와 시간 |
| `Scripts/Npc` | NPC 몸체, 이동, 감각, 경계, 순찰, 경비와 주민 FSM, 분대 조정 |
| `Scripts/Player` | 클릭 조작, 플레이어 타깃, 카메라, 소음 |
| `Scripts/World` | 맵 요소(문, 방, 웨이포인트, 은신처, 수색 더미), 연출(소음 링, 사격 효과), 애니메이션 보조 |
| `Scripts/Debug` | HUD, 디버그 오버레이, UI 입력 차단, 텍스처 |
| `Editor` | 씬 빌더 |
| `Config` | `AiTuningConfig.asset` |

## 1. Core: 공통 기반

### AiTypes.cs
공용 enum, 구조체, 인터페이스를 모아 둔 파일입니다.

- **`GuardState`**: Patrol, Investigate, Search, Chase, Return, Retreat, Ambush, Escape, Dead
- **`CivilianState`**: Routine, Flee, LockDoor, Hide, CautiousExit, FleeFallback, Beg, Escape, Dead
- **`AlertStage`**: Normal → Suspicious → Searching → CombatReady
- **`SquadRole`**: None, Pursue(추적), Flank(우회), GuardExit(출입구 경계)
- **`GuardTemperament`**: Coward(체력이 낮아지면 도주), Fighter(끝까지 싸움)
- **`CharacterAction`**: 애니메이터 트리거 이름(Attack, AttackAlt, Kick, HitReact, Block, Dodge, Die, Fire, Stagger)
- **`DefenseResult`**: None, Block, Dodge
- **`NoiseEvent`**: 소음 이벤트(읽기 전용 구조체). 위치, 크기, 출처 ID, 이벤트 ID를 담습니다.
- **`ThreatReport`**: 위협 보고(읽기 전용 구조체). 보고 ID, 보고자, 마지막 목격 위치, 신뢰도, 시각, 직접 목격 여부를 담습니다.
- **`IDefender`**: 공격을 막거나 피할지 판정하는 인터페이스
- **`IGraphAgent`**: 길찾기를 쓰는 대상이 구현하는 인터페이스

### AiTuningConfig.cs (ScriptableObject)
조정 가능한 수치를 한곳에 모은 에셋입니다.

| 그룹 | 주요 값 |
|---|---|
| 소음 | 걷기, 달리기, 문, 공격, 총성(1.6) |
| 경계 | 경계치 증가량: 소음 20, 목격 55, 시체 35, 보고 30 |
| 경계 | 감소: 지연 5초, 초당 6 |
| 경계 | 단계 문턱 20/50/80, 단계가 내려갈 때의 완충값 5 |
| F1 순찰 | 기본 경로 0.65, 다른 길 0.35, 직전 지점 반복 시 감점 0.5 |
| F1 순찰 | 대기 1~3초(Legacy 2초 고정), 조사 전 망설임 최대 0.8초 |
| F2 분대 | 통신 거리 8m, 보고 지연 0.5초, 보고 유효시간 8초, 보고 갱신 간격 2초 |
| F2 분대 | 추적조 최대 2명, 수색 지점 간격 2m |
| F2 분대 | 외침 거리 16m, 외침 소음 1.4 |
| F3 주민 | 도주, 문 잠금, 숨기 관련 수치 |

### AiDirector.cs
전역 관리자입니다(싱글턴).

- `Config`를 보관하고 모드를 관리합니다. Legacy는 원본처럼 동작하고, Enhanced는 F1~F3 개선이 켜진 상태입니다.
- 다른 스크립트는 `IsF1Active`, `IsF2Active`, `IsF3Active`로 기능이 켜져 있는지 확인합니다.
- QA용 단축키
  - F5: 모드 전환
  - F6: 재시작
  - F7: 시드 변경
  - F8: 무적
  - F9: 엑스레이(모든 방 보기)

### AiUtility.cs
여러 정적 헬퍼를 모아 둔 파일입니다.

| 클래스 | 역할 |
|---|---|
| `AiMath` | 3D 거리, 같은 층인지 판정(y 차이 0.6 미만), 수평 성분만 남기기(`Flat`) |
| `AiPhysics` | `IsOccluded` / `CountOccluders`: 두 점 사이의 벽과 닫힌 문 수를 레이캐스트로 셉니다. `Occluder`가 붙은 콜라이더만 대상이고, 미리 만든 버퍼를 써서 매번 메모리를 새로 잡지 않습니다(GC 없음). |
| `AiEventBus` | `NoiseEmitted` 이벤트. 소리를 내는 쪽과 듣는 쪽을 직접 연결하지 않도록 중간에 둡니다. |
| `AiIds` | 이벤트 ID 발급, 플레이어 출처 ID 상수 |
| `AiLog` | 디버그 오버레이에 띄우는 최근 로그 |

### Inventory.cs
- **`Inventory`**: 아이템 이름 상수(`Ammo` = "탄약", `Lockpick` = "락픽")
- **`NightClock`**: 밤 시간 계산
  - 21:00에 시작하고, 실제 1초에 게임 시간 1.4분이 흐릅니다(원본 영상에서 잰 값).
  - 04:30(450분 경과)에 경고, 05:00(480분 경과)에 종료합니다.
  - `Text`는 10분 단위로 끊어 표시합니다.

## 2. Npc: 적 AI

### NpcActor.cs
NPC 공통 몸체입니다. 경비와 주민 모두에 붙습니다.

- **기본 정보**: 체력, 종류(Guard/Civilian), 표시 이름, 눈 위치
- **피해 처리**: `ReceiveAttack(damage, canDefend, stagger, from)`
  - `IDefender.Defend()`에게 막기(피해 40%)나 회피를 물어봅니다.
  - `stagger`가 켜지면(완전 조준 사격) 0.7초 경직하고 0.5m 밀려납니다(Stagger 애니메이션).
  - 그 밖에는 HitReact나 Block 애니메이션을 재생합니다.
  - 맞으면 `Damaged(체력 비율, 공격 위치)` 이벤트를, 죽으면 `Died` 이벤트를 보냅니다.
- **대사**
  - `Say`: 일반 자막
  - `Shout`: 경보 외침. `IsShouting`이 켜지고 HUD가 큰 박스로 흔들며 표시합니다.
- **표시**
  - `SetVisibleToPlayer`: 플레이어 시야에 따라 보이거나 숨습니다.
  - 숨은 상태(`IsHidden`)면 렌더러를 아예 끕니다.
  - 경비와 주민의 색 구분은 MaterialPropertyBlock 틴트로 합니다.
- **`NpcActor.All`**: 모든 NPC 목록. 시야 처리와 HUD가 순회합니다.

### NpcMover.cs
웨이포인트 기반 이동기입니다(NavMesh는 쓰지 않음).

- **`SetDestination(target, penalty)`**
  - 목적지가 같은 층이면 직선으로 바로 갑니다.
  - 아니면 그래프로 경로를 구합니다(다익스트라).
  - 계단 위에서 출발하면 `TryGetSlopedEdgeAt`로 계단 양 끝 노드를 시작점으로 잡습니다. 계단 중간에서 아래층으로 떨어지는 문제를 막기 위해서입니다.
- **나머지 API**: `MoveDirect`, `Stop`, `FaceTowards`, `SetSpeed`
- **상태 값**: `IsMoving`, `HasArrived`, `IsBlocked`(잠긴 문에 막힘), `Destination`
- **문 발차기**: 속도 3 이상으로 닫힌 문(잠긴 문 제외) 1.1m 앞에 오면 0.4초 멈추고 Kick 애니메이션을 재생한 뒤 문을 엽니다. 이때 소음 1.1이 납니다.

### PerceptionSensor.cs
NPC의 감각입니다.

- **시각**: 시야각 안에 들어오고 거리 안이며, `AiPhysics`로 가림을 검사해 통과하면 봅니다. 플레이어가 숨어 있으면 보지 못합니다.
  - 이벤트: `ContactStarted`, `ContactUpdated(위치)`, `ContactLost`
  - 현재 보고 있는지는 `HasVisualContact`로 확인합니다.
- **청각**: `AiEventBus`를 구독합니다.
  - 체감 크기 = `loudness × (1 − 거리/8) × 0.6^(사이 벽 수)`
  - 체감 크기가 문턱을 넘으면 `NoiseHeard(이벤트, 체감 크기)`를 보냅니다.
- **시체 발견**: `CorpseFound`

### AlertMeter.cs
경비마다 따로 있는 경계 게이지(0~100)입니다.

- `Add`: 증가 / `Refresh`: 감소 지연만 리셋 / `SetValue`: 값 직접 설정
- `Tick`: 마지막 증거 후 5초 지나면 초당 6씩 감소
- 단계는 오를 때는 바로 오르고, 내릴 때는 문턱보다 5 더 낮아져야 내려갑니다. 문턱 근처에서 단계가 깜빡이지 않게 하기 위해서입니다.

### PatrolSelector.cs (F1-1)
순찰할 다음 지점을 고릅니다.

- 후보는 현재 노드와 연결된 노드 가운데, 자기 구역(순찰 경로 + 추가 노드) 안에 있고 지나갈 수 있는 노드입니다.
- 기본 경로의 다음 노드에 0.65, 나머지 노드들에 0.35를 나눠 줍니다. 직전 노드는 가중치에 감점을 곱합니다.
- 경로가 순환형이면 계속 돌고, 아니면 끝에서 되돌아옵니다.
- `NextWaitTime`: Enhanced 모드에서는 1~3초 사이 무작위, Legacy에서는 2초 고정입니다.
- 결정할 때만 난수를 뽑으므로, 같은 시드와 같은 입력이면 같은 선택이 나옵니다. `DecisionCount`로 결정 횟수를 추적합니다.

### GuardBrain.cs (가장 큰 파일)
경비 FSM입니다.

**초기화**
- 순찰용 난수와 전투용 난수를 따로 둡니다. 순찰 시드는 `baseSeed + id×1009`, 전투 시드는 `Seed ^ 0x5F3759DF`입니다. 전투 난수를 따로 둬서 전투가 순찰 패턴을 바꾸지 않게 했습니다.
- 성향(Coward 또는 Fighter)은 전투 난수로 50:50 결정합니다.
- 코디네이터에 자신을 등록하고, 감각 이벤트를 구독합니다.

**상태별 동작**

| 상태 | 동작 |
|---|---|
| Patrol | 이동 → 무작위 대기(좌우로 둘러봄) → 다음 지점. 의심 이상이면 속도 1.25배, 대기 0.6배, 더 자주 둘러봄 |
| Investigate | 잠깐 망설인 뒤(F1) 소음 위치로 이동하고, 도착하거나 막히거나 시간이 끝나면 Search |
| Search | 단서 주변 지점들을 돌며 1~2.5초씩 둘러봄. 보고받은 지점이 있으면 그곳을 쓰고, 출입구 경계조는 위치를 고수함. 시간이 끝나면 Return |
| Chase | 마지막으로 감지한 위치를 쫓음(실제 위치가 아님). 같은 층이면 직선, 아니면 그래프로 이동 |
| Return | 순찰 경로로 복귀. 경계치는 리셋하지 않고 자연 감소만 함 |
| Retreat | 겁쟁이가 체력 50% 이하로 맞으면 가까운 방으로 물러나 문을 잠금 |
| Ambush | 잠근 문 앞에서 대기. 접촉하면 바로 선공(조준 게이지 1) |
| Escape | 출구 노드로 도망쳐 도착하면 비활성화됨. 코디네이터에서도 빠짐 |
| Dead | 시체가 수색 가능한 LootPile이 됨. 소총을 든 경비면 탄약 6~12, 붕대 |

**Chase 중 전투**
- 사격(`UpdateRifle`)
  - 시야가 확보되고 사거리 안이며 가리는 것이 없으면 멈춰서 조준 게이지를 채웁니다. 가까울수록 빨리 찹니다.
  - 게이지가 매번 무작위로 정한 문턱(55~100%)에 닿으면 쏩니다.
  - 명중률은 게이지에 따라 35~90%이고, 0.12초 뒤 피해가 들어갑니다.
  - `GunFireFx.Shot`과 총성 소음을 냅니다.
- 근접
  - 사거리 밖이면 다가가서 공격과 대체 공격을 번갈아 씁니다.
  - 피해는 휘두르는 타격 시점(0.4초 뒤)에, 그때도 사거리 안일 때만 판정합니다.

**소음 반응 (F1, 경계 단계에 따라 다름)**
- 평온 상태 + 희미한 소리(체감 크기 0.35 미만) → 그쪽을 보고 1.2~2.8초 멈췄다가 순찰을 계속합니다.
- 의심 단계 → Investigate
- 수색 단계 이상 → 조사를 건너뛰고 바로 Search. 전투 준비 단계면 뛰어갑니다.
- 체감 크기가 강한 소음이면 의심 수준 보고(신뢰도 0.4)를 보냅니다.
- 경비가 낸 소리는 무시합니다(아군끼리 서로 반응하지 않도록).

**첫 발견**
- Chase로 전환합니다.
- 큰 소리로 외치고(쿨다운 20초) 소음 1.4를 냅니다.
- 외침 범위(16m, 벽과 층 무시)로 보고합니다.

**피격 (`OnDamaged`)**
- 공격 위치로 달려갑니다(Pursue).
- 겁쟁이가 체력이 한 번에 50% 이하로 떨어지면 Retreat나 Escape를 합니다.

**보고 수신 (`ReceiveReport`)**
- 유효시간이 지났거나 이미 처리한 보고는 무시합니다. Chase나 Escape 중에도 무시합니다.
- 경계치를 올리고 마지막 목격 위치를 갱신합니다.
- 역할을 소리 내어 알리고("내가 간다!", "반대쪽으로 돌아간다!", "출구는 내가 막는다!") Search를 시작합니다.

**그 밖의 기능**
- `Defend`: Chase 상태일 때만 회피나 막기를 굴립니다. 눈치채지 못한 경비는 기습을 그대로 맞습니다.
- `PromoteToFlank`: 출입구 경계조를 우회조로 올립니다.
- 숨은 플레이어 발견(`TryDiscoverHiddenPlayer`), 시체 발견 반응, 디버그 문자열 출력도 이 파일에 있습니다.

### SquadCoordinator.cs (F2)
경비 사이의 정보 공유와 역할 분담을 맡습니다.

- **`Submit(reporter, lkp, confidence, visual, shouted)`**
  - 보낼 때 받을 경비를 정합니다.
    - 일반 보고: 8m 이내이면서 같은 구역이거나 서로 보이는 경비
    - 외침: 16m 이내 경비 전부
  - 0.5초 뒤에 전달합니다. 보고자가 그 사이 죽으면 보고는 사라집니다.
- **`Deliver`** (역할 배정)
  - 이미 Chase 중인 경비는 추적조로 셉니다.
  - 나머지는 경로 비용 순으로 정렬합니다. 이미 수색 중인 경비는 비용에서 −100을 받아 역할이 유지됩니다.
  - 직접 목격한 보고면 중앙 추적 1명, 우회 1명(추적조 최대 2명)을 정하고, 나머지는 가장 가까운 출구 노드를 지킵니다(GuardExit). 갈 수 있는 출구가 없으면 우회로 돌립니다.
  - 의심 수준의 보고(직접 목격 아님)면 모두 우회 지점으로 갑니다.
- **수색 지점**
  - `FindFlankSlot`: 단서에서 간격~수색 반경 사이에 있는 노드
  - `FindExitSlot`: 출구 노드
  - `IsSlotTaken`: 경비끼리 정해진 간격 이상 떨어지게 합니다. 갈 수 없는 노드는 제외합니다.
- **`OnGuardDied`**: 추적조나 우회조가 죽으면 출입구 경계조를 우회조로 올립니다.
- **`Register` / `Unregister`**: 경비 목록 관리

### CivilianBrain.cs (F3)
주민 FSM입니다.

| 상태 | 동작 |

### PlayerClickController.cs (두 번째로 큰 파일)
원본처럼 모든 조작을 클릭으로 합니다(New Input System).

- **상호작용 버튼**
  - 매 프레임 주변의 문, 더미, NPC, 은신처 위에 원형 버튼을 만듭니다.
  - 버튼 종류: 문 열기/닫기/잠김, 수색, 줍기, 근접 공격, 기습, 사격, 숨기, 나오기, 엿보기, 그룹
  - 그룹: 중심 간 거리가 버튼 반지름의 1.9배 이내인 버튼들을 하나로 묶습니다(union-find). 묶음을 누르면 원형으로 펼쳐집니다.
  - 커서 모양은 바꾸지 않습니다.
- **이동**: 클릭 위치로 이동하고, 더블클릭이면 달립니다. 달리면 하얀 소음 링이 생기고, 닫힌 문은 발로 차서 엽니다.
- **대기 행동**: 클릭한 대상에 도착하면 그때 행동을 실행합니다.
- **시간 걸리는 행동**: 수색, 락픽, 쇠지레로 비틀어 열기. 진행 링을 표시하고, 맞으면 취소됩니다.
- **전투**
  - 근접: 쇠지레를 기본으로 들고 있다가 가까우면 근접 공격합니다. 상대가 모르는 상태면 기습이고, 기습은 막을 수 없습니다.
  - 사격
    - 조준 게이지가 피해량, 명중률, 경직을 결정합니다.
    - 명중률은 게이지에 따라 45~97%이고, 멀수록 떨어집니다(거리 보정 0.7~1).
    - 게이지를 끝까지 채우고 쏘면 상대가 경직됩니다.
    - 맞으면 게이지가 깎입니다.
  - 타격 판정은 `UpdateImpact`에서 지연 처리합니다.
- **수색 창 (`OpenContainerWindow`)**
  - 칸을 클릭하면 그 물건을 전부 가져오고, "모두 가져가기"가 있습니다.
  - 탄약은 `_ammo`, 락픽은 `_hasLockpick`, 나머지는 `Backpack`에 들어갑니다. 무게 제한은 없습니다.
  - 이동하거나, 더미가 비거나, 2.5m 넘게 떨어지면 자동으로 닫힙니다.
- **엿보기**: 문 뒤 방의 안개가 조금씩 걷힙니다(`RoomVolume.BeginPeek`).
- **숨기**: PlayerHideSpot에 숨어 있다가 지나가는 적을 기습할 수 있습니다.
- **밤 진행 (`UpdateNight`)**: 새벽 경고, 새벽 종료(`EndedAtDawn`), 출구 노드로 탈출(`HasExited`).

## 7. 설계 포인트

- **재현성**: 경비마다 시드를 고정하고 순찰 난수와 전투 난수를 분리해서, 같은 시드면 같은 순찰이 나옵니다.
- **느슨한 결합**: 소음은 EventBus, 보고는 Coordinator를 거쳐 전달되고, 각 Brain은 자기 감각과 받은 보고만 보고 판단합니다. 받은 보고는 다시 퍼뜨리지 않으므로 보고가 계속 돌아다니는 일이 없습니다.
- **Legacy/Enhanced 비교**: 모든 개선 로직을 `UseF1/F2/F3`로 감싸 두어서, F5 한 번으로 원본 동작과 비교할 수 있습니다.
- **GC 최소화**: 레이캐스트 버퍼, 경로 계산 임시 리스트, 소음 링, 사격 효과 객체를 미리 만들어 재사용합니다.
- **직렬화 보존**: 씬은 빌더가 만들고, 필드는 SerializedObject API로 설정합니다. 설정 에셋에 새로 넣은 필드는 기존 에셋에서 초기값을 그대로 씁니다.
