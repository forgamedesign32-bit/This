# TWOM 야간 탐색 NPC AI 개선 프로토타입 (Unity 3D)

명세서 `This_War_of_Mine_NPC_AI_Prototype_Spec.md` v1.0의 F1·F2·F3를 Unity 3D로 옮긴 구현.
원작은 2D 횡스크롤이지만, 여기서는 XZ 평면 기준 3D로 동일한 판단 규칙을 구현했다.
모든 수치는 **프로토타입 제안값**이며 원작 수치가 아니다.

## 1. 설치

1. Unity 6 프로젝트 (3D URP 또는 Built-in), Input System(New) 활성화.
2. Starter Assets - First Person + Third Person Character Controllers 임포트.
3. `TwomAi` 폴더를 `Assets/TwomAi` 로 복사 (v1에서 갱신 시 덮어쓰기).
4. **Tools → TWOM AI → Build Prototype Scene** → Play.

- `PlayerArmature` 프리팹을 **플레이어·경비·민간인 공용 모델**로 사용한다. 씬 생성 시 프리팹을 Unpack한 뒤 `ThirdPersonController`, `StarterAssetsInputs`, `PlayerInput`, `CharacterController`, `PlayerCameraRoot` 를 제거하고 Animator만 남긴다. `CharacterAnimator` 가 이동 속도로 `Speed`/`MotionSpeed`/`Grounded` 를 구동한다.
- 구분용으로 경비는 붉은 톤, 민간인은 푸른 톤 tint(MaterialPropertyBlock)만 적용. 프리팹이 없으면 캡슐로 대체.
- Starter Assets 카메라/Cinemachine/키보드 조작은 사용하지 않는다.

## 2. 조작 (원작 방식: 측면 단면 뷰 + 클릭)

| 입력 | 동작 |
|---|---|
| 좌클릭 바닥 | 걷기 (클릭 지점은 같은 층 보행선으로 스냅) |
| 좌클릭 더블 | 달리기 |
| 좌클릭 문 | 문 앞까지 이동 후 열기/닫기 (잠김 시 덜컹 소음) |
| 좌클릭 옷장 | 이동 후 수색 (숨은 민간인 발각) |
| 좌클릭 인물 | 접근 후 공격. 비경계 대상 = 기습 즉사 |
| 우클릭 | 행동 취소·정지 |
| 휠 | 줌 |
| A/D, ←/→ | 카메라 패닝 / Space 재중앙 |

- 다른 층 클릭 → 계단 경유 자동 경로. 닫힌 문은 경로상 자동으로 열리며 문 소음 발생.
- 커서 옆 임시 아이콘: `> walk`, `>> run`, `[H] open`, `[#] locked`, `[?] search`, `[X] attack`, `[X] sneak attack`.
- 하단 임시 버튼 바: `WALK/RUN 토글`, `STOP`, `AI: NEW/OLD`, `SEED +1`, `RESTART`, `DEBUG`.
- 경비 머리 위 `[?]` 의심 / `[!]` 수색 / `[!!]` 추격. 플레이어 발소리 `( step )` / `((( RUN )))`.
- QA 키: F5 모드, PgUp/PgDn 시드, F6 재시작, F7 무적, F8 중복 소음, F9 경계 70, Tab 디버그.

## 3. 테스트 맵 (2층, 정면이 열린 단면)

```
y=6.4 +=================== ROOF ===================+
      |      ......| Upper Hall      |  Safe Room   |   Door_SafeRoom (x=2, 2F)
 2F   |     /hole  | Guard_C         |  Civilian    |
y=3.2 +----/-------+-----------------+--[Wardrobe]--+
      |   / Entrance| Hall           |  Storage     |   Door_Storage (x=4, 1F)
 1F   |  /  Guard_A | Guard_B        |  [Wardrobe]  |
y=0 ==+(입구)-------+-----------------+--------------+
   x=-14  stairs -12.5~-7   x=-6       x=2/4        x=14
 Player spawn x=-19 (outside)
```

- 계단: 1층 x=-12.5 → 2층 x=-7. 2층 바닥은 계단 구멍이 뚫려 있어 그 사이로는 층간 시야가 통한다.
- 바닥/천장 슬래브는 `Occluder` → 층간 시야 차단, 소리는 벽 1개로 계산해 감쇠.
- Region: 0 입구, 1 홀, 2 안전방, 3 창고, 4 2층 복도, 5 외부. EXIT 노드: 건물 입구, 계단 꼭대기(GuardExit 배치 지점).
- 경비 A 입구~계단 아래, B 1층 홀, C 2층 복도. 민간인 2층 안전방.


## v3 변경 (전투 애니메이션 · 시야 · 원작 UI 싱크)

- **전투 애니메이션**: `Animations/` 의 Mixamo FBX 8종을 씬 생성 시 Humanoid로 재임포트(루트 모션 포즈에 굽기)하고,
  Starter Assets 컨트롤러를 복사한 `TwomCharacter.controller` 에 액션 상태를 추가한다.

  | 트리거 | 클립 | 사용처 |
  |---|---|---|
  | Attack / AttackAlt | Punching / Punching Bag | 일반 공격(번갈아), 경비 공격 |
  | Kick | Kicking | 플레이어 기습 공격 |
  | HitReact | Center Block | 피격 |
  | Block | Block | 경비 방어(피해 40%) |
  | Dodge | Dodging | 경비 회피(피해 0) |
  | Die | Dying | 사망(마지막 프레임 유지) |
  | Cower (bool) | Praying | 민간인 은신·웅크림, 플레이어 수집 중 |

  - 피해는 타격 프레임(0.35s, 킥 0.5s)에 사거리 재확인 후 적용.
  - 방어/회피는 **추격 중(플레이어 인지)인 경비만** 수행. 판정 난수는 순찰용과 분리된 스트림(시드 재현성 유지).
- **체력바**: 플레이어 포함 모든 인물 머리 위 하늘색 바. 그 위에 흰 자막으로 대사 출력(한국어).
- **시야 밖 암전**: `RoomVolume` 6개(거리/입구/홀/창고/2층 복도/안방). 플레이어 눈높이에서 벽·닫힌 문(`Occluder`)에 막히지 않는 방만 밝게, 본 적 있는 방은 반투명, 미탐색 방은 거의 검게. 보이지 않는 방의 인물은 렌더러·체력바·대사 모두 숨김.
- **충격파 링**: NPC 발걸음 = 빨간 링(암전된 방에서도 보임), 플레이어 달리기·문·공격 소음 = 흰 링. 걷기는 링 없음.
- **문**: 논리 상태는 즉시, 패널은 원작처럼 부드럽게 회전. 원형 아이콘 `[ ]` 열기 / `><` 닫기 / `|||` 잠김.
- **원작 HUD 싱크(임시 아트)**: 좌상단 종이띠(밤 18 · 시계 21:00부터 진행 · `|||` 수집 물품 수), `백팩`/`나가기` 바,
  주황 탭(`수집` 진행률, `맨손`), 좌하단 메시지 바(“전투중엔 수집할 수 없습니다.” 등), 우하단 폴라로이드 카드(파블 · 달리기가 빠름 · 상태),
  우상단 나가기 아이콘, 공격 조준 원형 커서, 탐색 종료/사망 카드.
- **수집**: 잔해 더미 3곳(`+` 아이콘) 클릭 → 2.5초 뒤 획득. 어느 경비든 추격 중이면 시작·진행 불가.
- **나가기**: 입구 밖 노드까지 달려가 탐색 종료.
- 개발용 UI는 Tab 디버그 패널로 이동(AI 모드, 시드, 재시작, X-RAY, 무적 버튼).
- IMGUI 기본 폰트로 한글을 출력한다. 글자가 네모로 보이면 OS 폰트 대체가 안 되는 환경이므로 알려줄 것.


## v4 변경 (중앙 버튼 상호작용 · 총기 · 조준 게이지)

- **커서 불변**: 마우스 커서 모양은 바뀌지 않는다. 모든 상호작용은 대상 **중앙의 원형 버튼**으로 표시되고 버튼을 클릭해야 실행된다.
  - 적: 몸 중앙(가슴 높이). 소총 장비 시 조준 링, 맨손 시 `공격`/`기습`.
  - 문 `문`/`닫기`/`|||`(잠김), 옷장 `?`, 잔해 `손`. 같은 층·시야 안·9m 이내에서만 표시.
  - 버튼이 없는 곳 클릭 = 이동(더블클릭 달리기), 우클릭 = 취소.
- **총기**: Low Poly Weapons의 `AK74`를 플레이어·경비 오른손 본(`HumanBodyBones.RightHand`)에 부착.
  v4.1: 손 본 고정 오프셋 방식 폐기. `WeaponMount` 가 매 프레임(애니메이션 이후) 양손 위치로 배치한다.
  양손이 가까우면(사격·조준·소총 걷기 클립) 오른손→왼손 방향으로 총열 정렬, 떨어지면 오른손에 총구를 아래로 든 휴대 자세.
  총열/위쪽 축은 메시 바운드로 자동 판별. 뒤집혀 보이면 `Rifle` 의 `WeaponMount` 에서 `Flip Barrel` / `Flip Up` 체크,
  쥐는 위치는 `Grip Fraction`, 손 보정은 `Hand Offset`. 재질은 URP용 `TwomAi/Materials/Gun.mat`(Textures_Guns)으로 교체.
- **무기 탭**: 좌측 주황 탭 `돌격 소총 (탄수)` / `맨손` 클릭으로 교체. 상단 종이띠 숫자 = 남은 탄약(원작과 동일 위치).
- **조준 게이지** (첨부 분석 문서 기준):

  | 조건 | 처리 |
  |---|---|
  | 적 버튼에 마우스를 올림 | 조준 대상 지정, 게이지 0부터 시작 |
  | 정지 상태 | 게이지 증가. 가까울수록 빠름 (`DistanceFactor`) |
  | 거리 | 도달 가능한 최대치(`AimCap`) 감소: 회색 점이 최대치 |
  | 플레이어 이동 | 게이지 감소(재조준 필요), 소총 걷기 애니메이션 |
  | 적이 시야/사선에서 사라짐 | 조준 해제 |
  | 플레이어 피격 | 게이지 -0.3 |
  | 클릭(사격) | 탄약 -1, 피해 = 12~70 × 게이지 × 거리 보정, 게이지 0으로 초기화 |
  | 최대 조준(십자 표시가 붉게) | 경직 + 넉백 (Stepping Backward) |

  - 적의 횡이동 자체 페널티는 문서상 미확인이므로 적용하지 않았다(거리 변화만 반영).
- **경비 사격**: 2.5~8m, 시야 확보 시 정지·조준, 게이지가 랜덤 임계값(0.55~1.0, 전투 전용 난수)에 도달하면 사격. 그보다 가까우면 근접전.
  총성은 `GunshotNoise 1.6` 소음 이벤트(흰/빨간 링 + 예광선).
- **애니메이션**: `Firing Rifle`(사격, 첫 프레임 = 조준 자세), `Rifle Walk`(조준 이동), `Stepping Backward`(경직).
  `Rifle Turn`, `Strafe Right` 는 프로젝트에 복사만 하고 아직 사용하지 않는다.


## v5 변경

- 총 파지: 오른손바닥=권총 손잡이, 왼손바닥=총열 덮개 두 점 정렬(중점 기준 오차 분산). `Guard Fraction` 추가(파랑 기즈모).
- 계단 블록을 보행선 뒤(z 0.25~1.45)로 이동: 카메라 쪽에서 캐릭터를 가리지 않음.
- 플레이어 혼잣말: 머리 위 자막. 시스템 안내("전투중엔 수집할 수 없습니다.")만 좌하단 메시지 바.
- 도구: 쇠지레 기본 소지(로우폴리 박스 모델, `HandPropMount` 로 주먹 관절선에 정렬). 소총 장비 중에도 적이 근접 거리면 버튼이 근접 공격으로 바뀌고 쇠지레로 타격.
- 잠긴 문: 락픽(조용, 4초, 소모) > 쇠지레(시끄러움, 2.2초, 0.6초마다 소음). 튼튼한 자물쇠(`_reinforced`)는 락픽만 가능.
- 락픽 경로: 1층 창고 `선반`에 락픽 → 2층 복도(경비 C) → 안방(민간인) → 잠긴 `금고방` 문(x=9) → `금고` 물품 6개.
- 시계: 영상 실측(0s 9:00pm, 40s 10:00pm, 140s 00:10am) 기준 약 1.4 게임분/초, 10분 단위 표시.
- HUD 위치: 원본 영상 1280×720 기준 좌표로 배치하고 화면 높이 비례 확대.


## v6: 매복(숨기 → 소리로 유인 → 기습)

- 매복 지점 2곳: 1층 입구/홀 통로 바로 안쪽(x=-5.1, 경비 A·B 동선), 2층 복도 중간(x=-3, 경비 C 동선). 벽 홈 + 엄폐 상자.
- `숨기` 버튼 → 홈 안(보행선에서 0.6m 뒤)으로 들어가 몸이 어두워지고 웅크림. 숨은 동안 NPC 시야에 잡히지 않는다.
- (v7) 소리 내기 기능 제거. 숨은 상태 버튼: `나오기`.
- 경비는 조사 중이라 플레이어를 인지하지 못한 상태 → 적 버튼이 `기습`, 클릭 시 즉사 공격.
- 발각: 경비가 매복 지점 1.1m 이내에서 1초 이상 둘러보면 "거기 숨어 있었군!" → 추격. 도착 직전이 기습 타이밍.
- 다른 행동(이동, 공격, 사격, 문 등)을 하면 자동으로 숨기 해제.
- 대사 자막: 원작처럼 어두운 박스 안에 표시.


## v7 변경

- 경비 피격: 공격 위치로 즉시 달려가 수색(+ 동료 보고). 한 번의 공격으로 체력이 50% 이하가 되면 `Retreat` → 문 있는 방(공격자 반대쪽 우선)으로 후퇴 후
  50%: 문 닫고 잠금 / 50%: 문 안쪽 매복(`Ambush`). 매복 중 플레이어를 보면 즉시 선공(쿨다운·조준 게이지 무시). 25초 후 잠금 해제·복귀.
- 민간인 피격: 도주. 체력 50% 이하 → 50% 확률로 `Beg`(Praying 클립, "제발... 살려주세요!") / 50% 플레이어 반대쪽 도주. 플레이어가 6m 밖으로 4초 떨어지면 다시 도주.
- 문 차기: 이동 속도 3 이상(달리기)으로 닫힌 문(잠김 제외)에 도달하면 Kick 애니메이션 + 큰 소음(1.1) + 0.4초 정지. 경비 소음은 다른 경비가 무시.
- 엿보기: 닫힌 문 버튼 쌍 `[문/|||] [엿보기]`. 문 앞에서 웅크려 엿보면 반대편 방 암전이 문 쪽부터 0.5m 띠 단위로 퍼지듯 걷히고 그 안의 인물이 보인다. 이동/다른 행동 시 종료.
- 백팩 UI: 원작식 어두운 패널 + 제목/무게(x/15) + 5×3 아이템 칸(이름·수량). 수집품은 종류별(목재/부품/통조림/약품).


## v8 변경 (원작 대비 보완)

- 수집 창: 뒤지기(시간 소요) 후 컨테이너 칸(왼쪽) + 백팩 칸(오른쪽)이 나란히 열림. 칸 클릭 = 그 항목 전부 담기, `모두 가져가기`, `닫기`.
  이동/다른 클릭/2.5m 이상 멀어지면 닫힘. 이미 뒤진 곳은 다시 클릭하면 바로 열림. 무게 제한 없음.
- 시체 수집: 쓰러진 경비는 탄약 6~12발(무장 시) + 붕대, 민간인은 통조림. 1.5초 뒤지기.
- 새벽 제한: 21:00 시작, 04:30 경고("곧 날이 밝습니다."), 05:00에 탐색 강제 종료("날이 밝았다.").

### v12 — 4층 맵 / 경보 외침 / 사격 연출

- **4층 건물:** 지그재그 계단 3개(A 0→1 좌, B 1→2 우, C 2→3 좌), 방 12개, 경비 5명(A~E), 주민 2명, 안전실 3곳(창고/거실/침실), 매복 지점 4곳, 금고(4층).
- **경보 외침:** 경비가 순찰·조사 중 처음 플레이어를 보면 큰 소리로 외칩니다.
  - 자막이 평소보다 큰 굵은 글씨, 큰 박스로 흔들리며 표시됩니다.
  - 소음 링이 생기고, ShoutRange(16m) 안의 경비는 벽과 층을 넘어 보고를 받습니다.
  - 20초 쿨다운이 있습니다.
- **사격 연출(원본 영상 기준):** 총구 앞에 짧고 강한 흰색 섬광(늘어진 원형)이 생기고, 0.09초 점광원이 방을 밝힙니다.
  - 총구에 연기가 피어오릅니다.
  - 명중하면 피 안개, 빗나가면 뒤쪽 벽에 먼지가 튑니다. 탄도선은 그리지 않습니다.
  - 조준 게이지에 따른 명중률: 플레이어 45~97%(거리 보정), 경비 35~90%.
- **F1 보강:** 경계 단계가 행동을 바꿉니다.
  - Normal 상태에서 희미한 소리를 들으면 그쪽을 보고 멈췄다가 순찰을 계속합니다.
  - Suspicious 이상이면 순찰 속도 1.25배, 대기 시간 0.6배로 바뀝니다.
  - Searching 이상이면 조사 단계를 건너뛰고 바로 수색합니다.

## 5. 기능별 구현 내용

### F1 가변 순찰·감지·경계
- 순찰: 경로상 다음 노드 65%, 연결된 구역 내 대체 노드 합계 35%, 직전 노드 가중치 ×0.5. 루프가 아니면 왕복. 대기 1~3초.
- 난수는 결정 시점에만 추첨. NPC별 `System.Random(baseSeed + npcId * 1009)`.
- 시야: `ViewDistance 6`, `ViewAngle 110`, 0.2초 주기, 0.4초 연속 노출 시 확정. 1.2m 이내는 각도 무시(근접 감지, 차폐는 적용).
- 청각: `effective = loudness * max(0, 1 - d/8) * 0.6^walls`, 임계 0.25. 발소리는 보폭마다 1회.
- 소음은 **위치 조사만** 유발. 추격은 시야로 얻은 LKP만 사용 (실제 플레이어 transform 추적 없음).
- 경계: 소음 +20 / 목격 +55 / 시체 +35, 5초 후 초당 -6, 하향 히스테리시스 5. `Return` 후에도 0으로 리셋하지 않음.
- 조사 최대 6초, 수색 최대 12초. 일반 하향 전이(Search→Return→Patrol)는 최소 2초 유지, 목격·사망은 즉시.
- F1 OFF: 고정 경로·고정 대기 2초·조사 망설임 없음·수색 순서 고정.

### F2 정보 공유·협동 수색
- 보고 조건: 직접 목격(확신 1.0, 접촉 중 2초마다 갱신), 시야 상실(0.7), 시체 발견(0.5), 강한 소음(유효 0.5 이상, 0.4, 4초 쿨다운).
- 전달: 범위 8m, 지연 0.5초, TTL 8초. 범위는 송신 시점 판정. 전달 전 보고자 사망 시 폐기.
- 중복: 수신자별 `HashSet<ReportId>`. 수신자는 재전송하지 않으므로 중계 루프 자체가 없음.
- 역할: 목격 보고 시 보고자 포함 최대 2명 `Pursue/Flank`, 나머지 `GuardExit`(가장 가까운 EXIT 노드). 수색 슬롯은 2m 간격, 도달 가능 노드만.
- 직접 목격한 경비는 역할과 무관하게 `Chase` 우선.
- TTL 만료 후 자체 단서가 없고 경계 단계가 `Searching` 미만이면 조기 복귀.
- Pursue/Flank 사망 시 GuardExit 경비를 Flank로 승격.

### F3 민간인 도주·잠금·은신
- 발소리만으로는 `"?"` 반응뿐, 직접 목격 시 `Flee`. 1회 구조 요청(F2 보고 재사용).
- 안전 방 비용: 경로 길이 + 플레이어 3m 이내 노드 페널티 30 + 은신처 만석 15 + 잠금 불가 10. 다른 사람이 잠근 방은 제외.
- 문 내측 0.6m 이상 진입 후 `TryClose → TryLock`. 문틀에 사람이 있으면 실패, 4회 실패 시 `FleeFallback`.
- 잠긴 문: 플레이어 E 입력 실패 + 문 흔드는 소음, NPC 경로 탐색에서 통과 불가.
- `HideSpot.OccupiedBy`로 중복 점유 방지. 플레이어가 은신처를 E로 조사하면 발각 → 문 열고 재도주.
- 10초 연속 위협 없음 + 시야 접촉 없음 → `CautiousExit`(2초 경청 → 문 열기 → 1초) → `Routine`. 그 사이 목격 시 즉시 재도주, 소음 시 재은신.
- Fallback: 위협에서 가장 먼 도달 가능 노드. 없으면 제자리 유지(이동 명령 반복 없음). 4초마다 안전 방 재탐색.

### LegacyMode
F1·F2·F3 모두 OFF인 비교용 단순 AI: 고정 순찰, 독립 소음 조사, 보고 없음, 민간인은 목격 시 `"!"`만 표시. 원작 코드의 복제가 아니다.

## 6. 설계 결정 (명세 해석)

- **2.5D 단면**: 모든 인물은 z=0 보행선 위를 이동. 거리는 3D, 시야 방향은 수평 facing 기준 3D 원뿔. 직선 이동·추격 지름길은 같은 층일 때만, 다른 층 목표는 계단 경로로 재탐색.
- **v1 파일**: `PlayerMeleeAttack.cs`, `PlayerInteractor.cs`, `FallbackPlayerController.cs` 는 빈 파일로 남겼다. 삭제해도 된다.
- **NavMesh 미사용**: 명세 요구대로 웨이포인트 그래프. NPC는 kinematic transform 이동이며 Rigidbody 없음.
- **차폐 판정**: 레이어 대신 `Occluder` 마커 컴포넌트 (벽, 닫힌 문 패널). 열린 문은 콜라이더가 꺼져 차폐 아님.
- **결정 재현성**: 같은 시드 + 같은 이벤트 순서에서 같은 선택. 실시간 플레이어 입력 자체는 프레임 타이밍이 달라 완전 재현되지 않으므로, QA-A01은 플레이어 개입 없이 순찰만 관찰하는 방식으로 검증한다.
- **슬롯 배정 시점**: 송신 시점이 아니라 전달 시점에 계산해, 보고자 자신의 수색 지점과 겹치지 않게 했다.
- **상태 최소 유지 2초**는 하향 전이에만 적용. 위협 관련 상향 전이는 즉시.
